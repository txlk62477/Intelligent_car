# 里程计空转与打滑检测待办

## 当前问题

当前 EKF 使用轮式 `vx` 和 IMU `gyro_z` 推算 `x、y、yaw`。编码器只能测量车轮转动，不能确认车身是否真正移动，因此小车悬空或打滑时可能累计虚假里程。

真实匀速移动与稳定空转都可能表现为：

```text
轮式 vx > 0，IMU ax ~= 0，IMU gyro_z ~= 0
```

所以只靠当前轮速和 IMU，无法可靠识别稳定的直线空转。参考项目的 EKF 也没有解决该问题；其全局位置稳定可能来自激光、AMCL 或 SLAM 修正。

## 后续思路

1. 启动和制动时，比较轮速加速度 `dvx/dt` 与 IMU `linear_acceleration.x`。
2. 转弯时，比较轮式 `angular.z` 与 IMU `gyro_z`，轮式角速度先只用于诊断，不直接融合。
3. 增加左右电机电流采样。相同轮速下，悬空通常比地面运行电流小；电流需结合 RPM、PWM 和电池电压标定，不能使用单一固定阈值。
4. 后期引入激光、视觉或光流速度，直接比较轮速与车身实际速度。

检测到异常后先发布诊断、降低轮式 `vx` 权重并增大协方差，不直接因为 `IMU ax ~= 0` 停止积分，因为真实匀速运动的加速度同样接近零。
