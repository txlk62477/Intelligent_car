# 小车启动指南

本文档只包含四步启动：micro-ROS Agent（Docker）、键盘控制、传感器融合过滤器节点、智能 Agent。

推荐启动顺序：

1. 启动 micro-ROS Agent（Docker）。
2. 启动过滤器节点（依赖 `/odom`、`/imu` 在线）。
3. 键盘控制 与 智能 Agent **二选一**（两者都发布 `/cmd_vel`，不能同时运行）。

每个 ROS 2 终端都需要先执行：

```bash
cd /home/lk/car/software/leap_ros_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
```

## 1. 启动 micro-ROS Agent（Docker）

```bash
docker run --rm -it \
  --name micro-ros-agent \
  --network host \
  microros/micro-ros-agent:jazzy \
  udp4 --port 8888 -v6
```

这是 UDP 网络通信，不需要挂载 `/dev`、挂载 `/dev/shm` 或使用 `--privileged`。正常情况下，Agent 会开始监听 UDP 8888，小车上线后终端会显示会话和实体创建日志。

如果使用非默认 ROS Domain，Docker 和宿主机必须一致。例如使用 Domain 10：

```bash
docker run --rm -it \
  --name micro-ros-agent \
  --network host \
  -e ROS_DOMAIN_ID=10 \
  microros/micro-ros-agent:jazzy \
  udp4 --port 8888 -v6
```

宿主机的每个 ROS 2 终端也要执行：

```bash
export ROS_DOMAIN_ID=10
```

未显式设置 `ROS_DOMAIN_ID` 时默认为 `0`。

验证 MCU 链路：

```bash
ros2 topic hz /odom
ros2 topic hz /imu
```

## 2. 启动键盘控制

前提：micro-ROS Agent 已启动，`/odom` 在线。

```bash
cd /home/lk/car/software/leap_ros_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash

ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

默认向 `/cmd_vel` 发布速度指令，按终端提示的按键（`i/j/k/l` 等）控制小车。

> 注意：键盘控制与智能 Agent **不能同时运行**——两者都发布 `/cmd_vel`，同时开启会产生指令冲突。

## 3. 启动过滤器节点（传感器融合）

前提：micro-ROS Agent 已启动，`/odom`、`/imu` 在线。

```bash
cd /home/lk/car/software/leap_ros_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash

ros2 launch xuegecar_sensor_fusion fusion.launch.py
```

数据流：`/odom`、`/imu` → 硬过滤节点（非有限值/物理阈值/单调重打戳/零偏/协方差）→ `/fusion/odom_valid`、`/fusion/imu_valid` → EKF（轮式 `vx` 为 6σ、IMU `gyro_z` 为 10σ 的宽松马氏门控）→ `/odometry/filtered`。

轮子悬空、打滑和电机电流辅助判断尚未实现，设计思路与后续实验见[里程计空转与打滑检测待办](./里程计空转与打滑检测待办.md)。

验证输出：

```bash
ros2 topic hz /odometry/filtered
ros2 topic echo /diagnostics
```

## 4. 启动智能 Agent

前提：micro-ROS Agent 已启动，**过滤器节点已启动**（网关读取 EKF 融合后的 `/odometry/filtered`，不再直接读 `/odom`）。

智能 Agent 由两个进程组成：Robot Gateway（ROS 2 侧，执行闭环控制）和 LangGraph Agent Server（语言交互与任务编排），通过本机 HTTP 连接。

### 终端 A：Robot Gateway

```bash
cd /home/lk/car/software/leap_ros_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash

ros2 launch xuegecar_agent_bridge gateway.launch.py
```

默认监听 `127.0.0.1:8765`，订阅 `/odometry/filtered`（`gateway.yaml` 的 `odom_topic` 参数），发布 `/cmd_vel`。

### 终端 B：LangGraph Agent Server

```bash
cd /home/lk/car/agents/car_agent
source .venv/bin/activate
langgraph dev --no-browser
```

Agent 通过 `ROBOT_GATEWAY_URL`（默认 `http://127.0.0.1:8765`）调用 Gateway，不直接发布速度。首次使用前确认 `.env` 中已填写 DeepSeek 密钥。

> 注意：智能 Agent 与键盘控制不能同时运行，两者都发布 `/cmd_vel`。
