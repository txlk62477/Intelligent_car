# 项目经验

## 智能Agent小车

**技术栈**：ROS2、Python 3、LangGraph、PostgreSQL、Nav2、YOLO、qwen3-vl:4b-instruct（Ollama 本地部署）、robot_localization（EKF）、HTTP/JSON、pytest

**项目描述**：基于 LangGraph + ROS2 的混合智能小车系统：LangGraph Agent Server 负责自然语言理解、任务编排、长期记忆与人工确认，ROS2 负责感知、定位、导航与实时控制，二者通过本机 Robot Gateway 的 HTTP/JSON 接口解耦连接，形成从自然语言指令到小车运动、跟随与导航的完整执行链路，支持问答、目标跟随、图像理解与命名地点导航。

**Agent 控制与长期记忆**：Supervisor 只做能力选择与结果解释，运动类副作用全部收敛到固定 Workflow 与 Gateway 实现，Agent 代码不导入 rclpy、不创建 ROS Publisher；基于 PostgreSQL 持久化（checkpointer + Store）构建长期记忆体系——用户 Profile 永久存储、对话 Episodes 180 天 TTL、地图地点永久保存，每轮对话自动加载记忆上下文并提炼稳定事实回写，Episodes 与地点经 qwen3-embedding 语义索引支持自然语言召回。

**目标跟随（YOLO）**：Supervisor 将自然语言目标转换为 YOLO COCO 英文类别，经检测快照确认候选后提交 FollowTarget 任务，由 ROS 控制节点闭环发布速度，支持最长 300 秒限时跟随、任务状态查询与取消。

**图像理解**：Ollama 本地部署 qwen3-vl:4b-instruct 视觉模型，支持读取用户指定图片与 Gateway 抓取相机当前帧进行描述与判断；视觉模型只输出理解结果，不直接控制底盘。

**命名地点导航（Nav2）**：按机器人/地图身份隔离解析地点标准名称与别名，无精确结果时语义召回、多候选交由用户选择；校验 AMCL 位姿新鲜度与协方差，ComputePathToPose 预检目标点净空，人工确认后幂等提交 NavigateToPose 并轮询终态；“保存位置”与“开始导航”双重确认，Gateway 持有独立导航超时，Agent 断连时仍可取消超时 goal 并锁止速度输出。

**EKF 多传感器融合定位**：基于 robot_localization 扩展卡尔曼滤波融合轮式里程计与 IMU 角速度（只融合轮式 vx、vyaw 与陀螺 z 轴角速度，MCU 积分位姿不直接进滤波器，避免轮速重复利用与轮距误差拉偏），四态运动状态机（静止/直行/原地转弯/弧线，阈值迟滞防抖）按状态切换融合比例——直行轮式:陀螺约 4:1，弧线 1:1，原地转弯反转为 1:4（打滑时轮式角速度系统性偏大，改信陀螺）；静止保持 0.2 s 后双路角速度零化，抑制陀螺零偏引起的航向漂移，检测到运动立即恢复；输出平滑连续的融合位姿，抑制轮子打滑与里程计累积漂移，为闭环运动控制与 Nav2 导航提供可靠定位输入。

**闭环运动控制与安全机制**：基于里程计实现距离投影、跨 ±π 航向累计与接近目标降速，统一速度仲裁、超时断联急停与人工接管；ROS 主线程独占控制闭环，HTTP 线程经线程安全队列提交命令、读取状态快照，HTTP JSON 按不可信输入严格校验。

## EKF 状态机分状态融合设计（面试问答用）

以下内容与仓库实际代码一一对应，用于面试时展开细节：

| 状态 | 进入条件 | 轮式角速度 stddev | 轮式:陀螺 权重比 | 依据 |
| --- | --- | --- | --- | --- |
| 静止 stationary | \|vx\| ≤ 0.005 m/s 且 \|wz\| ≤ 0.01 rad/s 持续 0.2 s | 双路角速度零化 | — | 抑制静止时 IMU 陀螺零偏造成的 yaw 漂移 |
| 直行 straight | \|wz\| 低于进入阈值 0.15 rad/s | 0.04 | ≈ 4:1 | 无打滑，轮式角速度更可信 |
| 原地转弯 turning | \|wz\| ≥ 0.15 rad/s 持续 0.1 s 且 \|vx\| < 0.05 m/s | 0.16 | ≈ 1:4 | 轮子打滑时轮式角速度系统性偏大，改信陀螺 |
| 弧线 arc | 转弯带内 \|vx\| ≥ 0.05 m/s | 0.08 | ≈ 1:1 | 打滑程度介于两者之间 |

设计要点：

1. **为什么不能只信单一传感器**：轮式里程计短期准确但打滑时角速度系统性偏大；陀螺短期无漂移但存在零偏（实测约 -0.00942 rad/s，已做补偿），长时间积分会缓慢漂移。
2. **状态机带迟滞**：进入/退出转弯带用不同阈值（0.15/0.10 rad/s），弧线判定用 0.05/0.03 m/s 迟滞，切换均需持续时长（enter 0.1 s / exit 0.2 s），防止阈值附近抖动导致融合权重反复跳变。
3. **离开静止是即时动作**：检测到运动立即解除零化约束，不吃掉起步角速度。
4. **EKF 只融合速度观测**：轮式 vx、轮式 vyaw 与陀螺 z 三路观测共同更新状态，MCU 已积分的 x/y/yaw 不进入滤波器（协方差标记为未使用），避免轮速信息重复进入滤波器、也避免轮距误差通过 MCU yaw 持续拉偏结果。
5. **权重比例通过观测协方差实现**：robot_localization 的 ekf_node 启动后不再动态改配置，状态机在门控节点里按当前相位改写输出消息的 twist.covariance（轮式角速度方差 0.04²/0.08²/0.16² 对应 4:1/1:1/1:4），EKF 依据协方差自动分配两路角速度观测的权重。
6. **外围保护**：宽松物理硬门控（幅值/变化率）拦野值，EKF 内马氏门控（轮式 6σ、IMU 10σ）兜底；全链路统一单调逻辑时钟（/clock），避免 WSL 系统时间回退破坏滤波时间轴。
7. **状态可见**：当前相位随 `/fusion/motion_phase` 话题发布，并在 `/diagnostics` 上报，便于现场排查。
